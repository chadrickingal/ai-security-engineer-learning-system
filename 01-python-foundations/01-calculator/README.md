# CLI Python Calculator

A simple cli calculator built with python

## Features 

- Addition
- Subtraction
- Multiplication
- Division
- Error handling

## Requirements

Python 3.10 or higher

## Usage

Run the application:

```bash
python main.py
```

Example:

```text
============================
CLI Simple calculator
============================

Numbers
:10
:20

Operator |+|-|*|/|
:+

Addition (+)
Result: 10 + 20 = 30

Calculate again? [Y/n]
:n
```
