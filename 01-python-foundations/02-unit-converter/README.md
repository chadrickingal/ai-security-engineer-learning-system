# CLI Python Unit Converter

CLI unit converter built with python

# Features

- centimeter to inches    | cm > in
- milimeter to inches     | mm > in
- meter to feet           | m  > ft
- kilometer to miles      | km > mi
- centimeter to feet      | cm > ft
- inches to feet          | in > ft
- meter to yard           | m  > yd
- centimeter to kilometer | cm > km
- testing
- error handling


# Usage

Example: 

```bash

        ================================================================
                             CLI UNIT CONVERTER
        ================================================================
        +--------------------------------------------------------------+
        | No. | Units         | No. | Units      | No. | Units         |
        +-----+---------------+-----+------------+-----+---------------+
        | (1) | cm -> in      | (2) | mm -> in   | (3) | meter -> feet |
        +-----+---------------+-----+------------+-----+---------------+
        | (4) | km -> miles   | (5) | cm -> feet | (6) |in -> feet     |
        +-----+---------+-----+-----+------------+-----+---------------+
        | (7) | meter -> yard | (8) | cm -> km   |     |               |
        +--------------------------------------------------------------+
        
Please provide values below
-------------------------------
Unit: 4
Number: 3

------------------------------------
        kilometer to miles
------------------------------------
3.0km --> 0.0186mi

____________________________________
You want to convert again? Y/n
: n

```
